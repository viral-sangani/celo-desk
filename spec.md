# Celo Desk — Technical Spec

> Bloomberg-style terminal for AI agents trading bluechip tokens and FX pairs on Celo.
> 48-hour hackathon project.

---

## 1. Overview

Celo Desk is a real-time dashboard that monitors AI agents trading on the Celo blockchain. Agents autonomously create wallets, read market data + news, and execute trades on a recurring schedule (every ~5 minutes). The platform earns 0.1% fees on every swap.

Two views:
1. **Terminal** — single-agent trading dashboard (price charts, FX grid, watchlist, portfolio, news feed)
2. **Global** — platform-wide analytics (TVL, volume, fees, leaderboard, activity feed)

## 4. Convex Schema

```typescript
// convex/schema.ts
import { defineSchema, defineTable } from "convex/server";
import { v } from "convex/values";

export default defineSchema({
  // AI trading agents
  agents: defineTable({
    name: v.string(),                    // e.g. "alpha-seeker-7"
    walletAddress: v.string(),           // Thirdweb-generated wallet
    status: v.union(v.literal("active"), v.literal("paused"), v.literal("stopped")),
    portfolioValue: v.float64(),         // Current total value in USD
    pnl: v.float64(),                    // Cumulative PnL in USD
    pnlPercent: v.float64(),             // PnL as percentage
    totalTrades: v.float64(),            // Trade count
    winRate: v.float64(),                // Win rate 0-1
    tradeIntervalMs: v.float64(),        // Trading frequency in ms (default 300000 = 5min)
    lastTradeAt: v.optional(v.float64()),// Timestamp of last trade
    nextTradeAt: v.optional(v.float64()),// Timestamp of next scheduled trade
    createdAt: v.float64(),
  }).index("by_status", ["status"])
    .index("by_pnl", ["pnlPercent"]),

  // Agent token holdings
  holdings: defineTable({
    agentId: v.id("agents"),
    token: v.string(),                   // Token symbol e.g. "CELO", "cUSD"
    amount: v.float64(),
    valueUsd: v.float64(),
    allocationPercent: v.float64(),
  }).index("by_agent", ["agentId"]),

  // Trade history
  trades: defineTable({
    agentId: v.id("agents"),
    fromToken: v.string(),
    toToken: v.string(),
    fromAmount: v.float64(),
    toAmount: v.float64(),
    priceUsd: v.float64(),
    feeUsd: v.float64(),                 // 0.1% platform fee
    txHash: v.string(),
    timestamp: v.float64(),
  }).index("by_agent", ["agentId", "timestamp"])
    .index("by_timestamp", ["timestamp"]),

  // Token price snapshots
  prices: defineTable({
    token: v.string(),                   // "CELO", "cUSD", etc.
    priceUsd: v.float64(),
    change24h: v.float64(),              // Percentage
    marketCap: v.optional(v.float64()),
    volume24h: v.optional(v.float64()),
    timestamp: v.float64(),
  }).index("by_token", ["token", "timestamp"]),

  // FX rates for Mento stablecoins
  fxRates: defineTable({
    pair: v.string(),                    // e.g. "cUSD/USD", "cEUR/EUR"
    price: v.float64(),
    change24h: v.float64(),
    spread: v.float64(),
    timestamp: v.float64(),
  }).index("by_pair", ["pair", "timestamp"]),

  // News & market feed
  news: defineTable({
    source: v.string(),                  // "YAHOO", "TRADINGVIEW", "FINVIZ", "SEEKING_ALPHA"
    headline: v.string(),
    url: v.optional(v.string()),
    timestamp: v.float64(),
  }).index("by_timestamp", ["timestamp"]),

  // Platform-wide aggregated metrics (updated periodically)
  platformMetrics: defineTable({
    tvl: v.float64(),
    tvlChange24h: v.float64(),
    totalTrades24h: v.float64(),
    totalVolume24h: v.float64(),
    totalFeesEarned: v.float64(),
    activeAgents: v.float64(),
    avgTradeFrequencyMs: v.float64(),
    timestamp: v.float64(),
  }).index("by_timestamp", ["timestamp"]),

  // Platform activity log
  activityLog: defineTable({
    type: v.union(
      v.literal("trade"),
      v.literal("agent"),
      v.literal("fee"),
      v.literal("alert")
    ),
    message: v.string(),
    agentId: v.optional(v.id("agents")),
    timestamp: v.float64(),
  }).index("by_timestamp", ["timestamp"]),
});
```

### Top Bar (shared)
- Left: "CELO DESK" in terminal-style monospace
- Center: Nav tabs — "GLOBAL" and "TERMINAL" (link to `/global` and `/terminal`)
- Right: Current UTC time (live updating), Celo network status (green dot + "MAINNET")

### Terminal Page (`/terminal`)

CSS Grid layout: 2 columns, 2 rows

```
┌─────────────────────────┬──────────────────┐
│                         │   FX Rates Grid   │
│   Live Price Chart      ├──────────────────┤
│   (candlestick)         │    Watchlist      │

│   Agent Portfolio       │   News & Social   │
│   (holdings + PnL)      │      Feed         │

```

- **Price Chart (top-left, ~60% width, 50% height):** TradingView Lightweight Charts candlestick. Token selector dropdown (CELO, cUSD, cEUR, cREAL). Timeframe tabs: 1H, 4H, 1D, 1W. Large current price display. Volume bars at bottom.
- **FX Rates Grid (top-right, ~40% width, 25% height):** Table — Pair, Price, 24h Change %, Spread. Mento stablecoins: cUSD/USD, cEUR/EUR, cREAL/BRL, cKES/KES, cCOP/COP, etc.
- **Watchlist (top-right below FX, ~40% width, 25% height):** Table — Token, Price, 24h Change, Market Cap. Sparkline mini-charts per row.
- **Portfolio (bottom-left, ~60% width, 50% height):** Header "AGENT PORTFOLIO". Total value, PnL (absolute + %). Holdings table: Token, Amount, Value, Allocation %, 24h PnL. Small donut chart for allocation. Agent status indicator + next trade countdown.
- **News Feed (bottom-right, ~40% width, 50% height):** Scrollable feed. Each item: timestamp + source badge ([YAHOO], [TRADINGVIEW], etc.) + headline. Most recent first.

### Global Page (`/global`)

Vertical stack layout: 4 rows

```
┌──────────────────────────────────────────────┐
│  TVL | Trades | Volume | Fees | Agents | Freq │  ← Metrics Strip
├──────────────────────┬───────────────────────┤
│   TVL Over Time      │   Trading Volume      │
│   (area chart)       │   (bar chart)         │
├──────────────────────┼───────────────────────┤
```

## 7. Convex Functions (Backend)

### Queries (real-time, reactive)
```
prices:getLatest(token) → latest price snapshot
prices:getHistory(token, timeframe) → price history for charts
fxRates:getAll() → all current FX rates
agents:get(agentId) → single agent details
agents:getHoldings(agentId) → agent's token holdings
trades:getRecent(agentId, limit) → recent trades for an agent
news:getRecent(limit) → latest news items
analytics:getLatestMetrics() → current platform metrics
analytics:getMetricsHistory(timeframe) → TVL/volume over time
analytics:getRevenueBreakdown() → fees by pair
agents:getLeaderboard(limit) → top agents by PnL
activityLog:getRecent(limit) → recent platform events
```

### Mutations
```
agents:create(name, walletAddress) → create new agent
agents:updatePortfolio(agentId, holdings) → update agent holdings/PnL
trades:record(agentId, tradeData) → log a completed trade
prices:upsert(token, priceData) → update price snapshot
news:add(source, headline, url) → add news item
activityLog:add(type, message) → log platform event
analytics:updateMetrics() → recalculate platform aggregates
```

### Actions (external API calls)
```
scraper:fetchPrices() → scrape Yahoo Finance / TradingView for prices
scraper:fetchNews() → scrape news from Yahoo Finance, Seeking Alpha, Finviz
agent:executeTrade(agentId) → agent reads market data + news → Gemini decides → execute swap via Uniswap
```

### Cron Jobs (Convex scheduled functions)
```
every 1 minute  → scraper:fetchPrices (update token prices + FX rates)
every 5 minutes → scraper:fetchNews (fetch latest news)
every 5 minutes → agent:executeTrade for each active agent
every 5 minutes → analytics:updateMetrics (recalculate platform aggregates)
```

## 12. Notes for Claude Code

- **Start with mock data.** Get the UI looking right before wiring real APIs. Seed Convex with realistic placeholder data.
- **Convex is the only backend.** No Express, no separate API. All server logic lives in `convex/` folder as queries, mutations, and actions.
- **Convex queries are reactive.** Use `useQuery()` hook — components auto-update when data changes. No polling needed for UI updates.
- **Terminal aesthetic is critical.** Monospace fonts for all data. Sharp corners. Dark bg. Thin borders. Amber headers. Green/red for price direction. This is the hackathon differentiator.
- **Keep it minimal.** Don't over-engineer. No auth system. No user accounts. Single agent view for terminal. The visual impact + real-time data is what wins hackathons.
- **TradingView Lightweight Charts** is a standalone library (not the full TradingView widget). Import and use it directly: `import { createChart } from 'lightweight-charts'`.
- **Convex cron syntax:** Convex uses its own cron format, not standard unix cron. Check Convex docs for `crons.interval()` and `crons.cron()`.
